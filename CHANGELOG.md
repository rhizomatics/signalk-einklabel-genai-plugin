# [0.3.0]

- Update timeout to 60 seconds to handle slower local or free models
- Better handle retry for responses that don't have cleanly extractable SVG
- OpenRouter model and token usage now logged
- Strip HTML punctuation that breaks XML before converting SVG

# [0.2.0]

- AI providers drop-down now restricted to available AI SDK plugins
- Test option added to validate AI configuration, keys and connectivity

# [0.1.1]

- Packaging fixes

# [0.1.0]

- Initial release with support for major cloud GenAI services and local LLMs
- As an alternative to a template, an image can be generated by an LLM based on customized prompt
  - Prompt will automatically include details of the ESL, including available colours, height, width, manufacturer and locally supported fonts
- A marine forecast prompt is provided as an example
  - It automatically includes vessel length, type and position.
- The [Vercel AI SDK](https://ai-sdk.dev) is used, so a wide range of [providers](https://ai-sdk.dev/providers/ai-sdk-providers) are supported by the framework, although only a handful of the major ones imported to minimze bloat. These are all optional dependencies, so the plugin will not fail to load if they are unavailable, and they can be omitted if installing directly using `npm`
  - [Anthropic](https://ai-sdk.dev/providers/ai-sdk-providers/anthropic) (Claude)
  - [Google](https://ai-sdk.dev/providers/ai-sdk-providers/google) (Gemini)
  - [OpenAI](https://ai-sdk.dev/providers/ai-sdk-providers/openai) (ChatGPT)
  - [xAI](https://ai-sdk.dev/providers/ai-sdk-providers/xai) (Grok)
  - [Moonshot AI](https://ai-sdk.dev/providers/ai-sdk-providers/moonshotai) (Kimi)
  - [DeepSeek](https://ai-sdk.dev/providers/ai-sdk-providers/deepseek)
  - [Ollama](https://ai-sdk.dev/providers/community-providers/ollama) - local and cloud using the offical API
  - [OpenAI Compatible](https://ai-sdk.dev/providers/openai-compatible-providers) - including local LM Studio
